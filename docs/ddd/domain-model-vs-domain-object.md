# ドメインモデルとドメインオブジェクトの違い

## ドメインモデルとは

ドメインモデルとは、業務知識やビジネスルールを抽象化した概念モデルのこと。コードだけに限らず、ドキュメントやチーム内の会話も含めて共有される「業務の理解そのもの」を指す。

## ドメインオブジェクトとは

ドメインオブジェクトとは、ドメインモデルをコードとして実装したもの。エンティティや値オブジェクトなど、具体的なクラス・オブジェクトとして表現される。

## 関係整理

- **ドメインモデル**: 抽象的な概念・業務知識の体系（設計図にあたる）
- **ドメインオブジェクト**: それをコードに落とし込んだ実体（実装物にあたる）

ドメインモデルはドメインオブジェクトより広い概念であり、ドメインオブジェクトはドメインモデルを表現する手段の一つ。

## 値オブジェクトについて（補足）

値オブジェクト（Value Object）は、DDDにおけるドメインオブジェクトの一種。エンティティがID（識別子）によって同一性を判定されるのに対し、値オブジェクトは属性値そのものによって同一性が決まる。そのため多くの場合、IDを持たず不変（イミュータブル）に設計される。
