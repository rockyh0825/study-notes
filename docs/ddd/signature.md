# シグネチャとは

## シグネチャの定義

プログラミングにおける「シグネチャ（signature）」とは、メソッドや関数を一意に識別するための情報の組み合わせのこと。具体的には以下の要素からなる。

- メソッド名
- 引数の型・個数・並び順

言語によっては戻り値の型をシグネチャに含める場合と含めない場合がある。例えばJavaはオーバーロード解決に戻り値の型を使わないため、戻り値の型はシグネチャに含まれない。

## なぜシグネチャが重要か

- **オーバーロードの識別**: 同名メソッドでも引数の型・個数・並び順が異なれば、別メソッドとして扱われる（メソッドオーバーロード）
- **インターフェースの契約**: シグネチャは、そのメソッドが「何を受け取り、何を返すか」を外部に伝える契約になる
- **可読性・意図の明確化**: メソッドのシグネチャを分かりやすい名前・型にすることで、コード自体が意図を表現するようになる

## DDDとの関わり

DDDではリポジトリやドメインサービス、エンティティのメソッドを設計する際、シグネチャ（メソッド名・引数の型）が業務の意図を正確に表現しているかが重要視される。

例えば、引数にプリミティブ型ではなく値オブジェクトを使うと、シグネチャ自体が制約や意味を語るようになる。

```
// 意図が曖昧
withdraw(int amount)

// シグネチャ自体が制約・単位を表現している
withdraw(Money amount)
```

このように、シグネチャの設計はユビキタス言語をコードに反映させる手段の一つでもある。
